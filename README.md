# Git Practice Project 🚀

مشروع إثبات تطبيق عملي لأساسيات Git و GitHub.

## 🛠️ الأوامر المطبقة:
* **Workflow:** `git init` | `git add .` | `git commit` | `git status`
* **Inspection:** `git log --oneline` | `git diff`
* **Undo:** `git restore`
* **Branching:** `git checkout -b` | `git branch` | `git merge` | `git branch -d`
* **Remote:** `git remote add origin` | `git push`
